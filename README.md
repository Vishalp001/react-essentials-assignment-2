📋 Task Manager Application (React + Context API + useReducer)
🚀 Overview
Link: https://taskmanagervishal.netlify.app/
This is a Task Manager Application built using React, leveraging the Context API and useReducer hook for global state management.

The app allows users to:

Add tasks
Edit tasks
Delete tasks
Mark tasks as complete/incomplete
View task summaries

The primary goal of this project is to demonstrate scalable state management, eliminate prop drilling, and maintain a clean separation between logic and UI.

🧠 Core Concepts Used
React Context API → Global state sharing
useReducer Hook → Managing complex state logic
Component-based Architecture → Modular & reusable UI
Separation of Concerns → Logic vs UI
✨ Features
📝 Task Management
Add new tasks
Edit existing tasks
Delete individual tasks
Clear all tasks
Toggle task completion status
📊 Task Summary
Total number of tasks
Number of completed tasks
Real-time updates
🎨 UI/UX Enhancements
Clean and centered layout
Hover effects on buttons
